# commit

Instruction:

Analise as alterações do repositório Git executando `git status`, `git diff` e `git diff --staged`. Com base apenas no diff real, responda em português com uma **branch sugerida** (`tipo/descricao-em-kebab-case`, prefixos: feat, fix, refactor, chore, docs, test, ci) e uma **mensagem de commit** no estilo Conventional Commits (primeira linha curta; corpo opcional). Siga o fluxo e o formato de resposta detalhados em `.cursor/skills/commit/SKILL.md`. Não invente mudanças que não apareçam no diff.
